МОНОПРИНТ - отдельный 3D-конструктор кружки

Файлы:
- index.html
- styles.css
- app.js
- mug.glb - загруженная GLB-модель

Как запустить:
1. Не открывайте index.html двойным кликом - браузер может запретить загрузку GLB.
2. Запустите папку через локальный HTTP-сервер.
   Вариант с Python: python -m http.server 8080
3. Откройте http://localhost:8080

Функции:
- 3D вращение и масштаб кружки
- загрузка PNG/JPG/WEBP
- перетаскивание изображения мышью
- масштаб и поворот
- Вписать / Заполнить / По центру
- синхронное нанесение изображения на материал art_here модели
- экспорт PNG области печати 210x95 мм
- экспорт PNG 3D-превью
- адаптивная мобильная версия

Примечание: Three.js подгружается с CDN, поэтому при первом запуске нужен интернет.
